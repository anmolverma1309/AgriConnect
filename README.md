# AgriConnect 🌾🤖

**End-to-End AI-Powered Agricultural Platform**

AgriConnect is a comprehensive platform designed to empower farmers with the latest advancements in Artificial Intelligence and predictive modeling. It bridges the gap between sophisticated technology and the agricultural sector, offering actionable insights directly to the hands of farmers.

---


## 🚀 Key Features

*   **Crop Disease Detection**: Utilizes a Convolutional Neural Network (CNN) image classification model to detect crop diseases with over 92% accuracy across 38 distinct plant/disease classes.
*   **Yield Prediction**: Machine learning regression models trained on extensive real-world agricultural datasets to predict crop yields based on environmental factors.
*   **Real-Time Market APIs**: Integrates with 3 distinct real-time market price APIs, providing farmers with up-to-date economic data to maximize their profits.
*   **Offline SMS Alerts**: Crucial for rural areas with low connectivity, the platform sends critical offline alerts via SMS.
*   **Cross-Platform App**: A seamless user experience delivered through a Flutter-based mobile application.

---

## 🛠️ Tech Stack

*   **Frontend / Mobile**: Flutter, Dart
*   **Backend / Cloud**: Microsoft Azure, Firebase, REST APIs
*   **AI / ML**: Python, TensorFlow, Keras, Scikit-Learn
*   **DevOps**: GitHub Actions (CI/CD Pipeline)

---

## 📖 Project Impact

By combining highly accurate computer vision for disease diagnosis with predictive yield analytics and real-time market data, AgriConnect serves as an all-in-one assistant for farmers. It not only helps in mitigating crop loss but also ensures economic sustainability through informed decision-making.
